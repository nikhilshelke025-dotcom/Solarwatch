SOLARWATCH Solar Monitoring System — clickable demo prototype

HOW TO RUN
1. Extract SOLARWATCH_Prototype.zip.
2. Open index.html in Chrome, Edge, or Firefox.
3. Use Refresh data, site selector, chart range, and Mark all reviewed to try interactions.

WHAT IS INCLUDED
- Dashboard UI with simulated power, daily energy, temperature and data availability
- Power generation chart with today/yesterday selector
- Target progress, device table, sample alerts and example calculations
- Responsive desktop/mobile layout

IMPORTANT
This is a front-end demonstration only. Values are simulated; no ESP32, INA219, DS18B20,
ThingSpeak, Supabase, or other backend is connected. For a real prototype, build the low-voltage
DC sensor hardware, calibrate against a reference meter, then connect a data service. Never
connect a student breadboard prototype to mains AC, high-voltage PV strings or inverter internals.
